# 指标口径说明（摘要）

> 唯一真源：[docs/口径-metrics.md](口径-metrics.md)（v1.0 定稿，含公式、边界与实现位置）。
> 本文是**交付用摘要**：给业务/验收同学快速对齐口径，不替代原文；两处冲突时以原文与代码为准。

## 1. 主指标

| 指标 | 口径 | 取值 / 方向 |
|---|---|---|
| **AUC** | Mann–Whitney U，`P(s_bad > s_good) + 0.5·P(s_bad = s_good)`；并列取平均秩 | `[0,1]`；`AUC < 0.5` 表示方向相反（**不自动翻转**） |
| **Gini** | `2·AUC − 1`，不独立实现（避免口径漂移） | `[-1,1]` |
| **KS** | `max_t｜F_bad(t) − F_good(t)｜`；按**分数值整组**推进，同分客户不拆开 | `[0,1]`；取绝对值，方向由 `score_direction` 单独给 |
| **LIFT@pct** | 段内坏样本率 / 整体坏样本率；按风险降序取尾部累计权重首次 ≥ pct | `≥0`；`LIFT=0` 是真实值（尾部没抓到坏样本），看 `lift_seg_size` / `is_reliable` |
| **IV（分箱）** | `Σ (bad_pct_i − good_pct_i)·WOE_i`，带 `woe_smoothing`（默认 0.5）；稀疏箱先合并 | `≥0`；**读数依赖箱数**，报表同时给 `requested_bins` 与实际箱数 |
| **PSI** | `Σ (test_i − base_i)·ln(test_i / base_i)`，同一套箱；缺失箱参与、test 不存在的箱按 0、分母 `eps=1e-6` | `≥0`；越小越稳 |

方向约定：统一用 `score_direction(y, s)` 判定（`AUC ≥ 0.5` ⇒ `higher_score_higher_risk`），
各报表不得自行翻转。

## 2. 跨期与多分类

- **分月评估**：`model_evaluate` 的分数 PSI 用「基期合并池」拟合切点、各月共用；
  默认基期 = 最早月，可用 `config.psi_base_months` 合并；基期覆盖全部月 / 只有 1 个月 /
  无时间列 ⇒ `psi.enabled=false` + `reason`，**不伪造数值**；
- **闸门用哪个 PSI**：`psi.max_psi`（各对比月 PSI 的**最大值**），不是平均、不是 `overall_psi`；
- **多分类**：逐类 OVR（one-vs-rest），`AUC/KS/Gini/LIFT` 各自算；主结论用 **macro**
  （有效类算术平均），`weighted` 仅参考；
- **多分类 bad_class**：KS/LIFT 表与图先把标签二值化为 `y == bad_class`；表内 `Σbad`
  必须等于坏类样本数；多分类的分数 PSI 用 `bad_class` 那一列概率（不是 argmax）。

## 3. 确认阈值（`model_confirm`）

默认：**KS ≥ 0.25**、**PSI ≤ 0.10**（`thresholds={ks_min, psi_max}` 可覆盖，`ks_min ∈ [0,1]`、
`psi_max ≥ 0`，越界 ⇒ `config_invalid`）。

判定规则（详见 [口径-metrics.md §8](口径-metrics.md)）：

1. **KS 取值**：`val` 优先；val 指标被跳过（该子集只有一类标签）时回落 `train`，
   `ks_source` 显式返回 `val` / `train`，不混用；
2. **PSI 取值**：`psi.max_psi`；`psi.enabled=false` ⇒ 该项跳过，但 warnings 必须写
   「PSI 未计算，只校验 KS —— 不代表跨期稳定」；
3. **通过条件**：`ks ≥ ks_min` 且（PSI 不可用 或 `psi ≤ psi_max`）；
4. **不通过**：`error.code=threshold_not_met`，`data` 给
   `ks / ks_gap / psi / psi_gap / failed_checks / checks`（差距值，不给"差不多就行"）；
5. **通过**：写 `final/model.pkl` + `final/confirm.json` + `manifest.confirmed_run`，
   run 状态变 `confirmed`；
6. val 样本量 < 100 ⇒ 附「可靠性有限」告警（阈值判断统计波动大），但仍允许确认；
7. **多分类**主指标取 **macro KS**，阈值与二分类同一套；`bad_class` 的 OVR KS 只作诊断读数。

> 示例宽表（坏率约 1.75%）实测：val KS ≈ 0.402（过线）、最差月 PSI ≈ 0.115（**超过 0.10** ⇒
> 默认阈值会故意拦下）。`tests/test_e2e_flow.py` 同时验证严阈值确实会拦，并用宽松阈值覆盖通过路径。
