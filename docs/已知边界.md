# 已知边界与未验证项

> 原则：**未通过 / 未实测 / 降级必须如实标注，不臆造结论**。
> 本文只列边界事实与处置建议；具体实现与阈值见 [tool-contract.md](tool-contract.md)、
> [口径-metrics.md](口径-metrics.md)、[model-layer.md](model-layer.md)。

## 1. 数据与结果边界

| # | 边界 | 事实 / 影响 | 处置 |
|---|---|---|---|
| 1 | **极少坏样本时指标波动大** | 坏率约 **1.75%**（35/2000）的宽表上，val/test 各约 7 个坏样本，KS/AUC/LIFT 统计波动大 | 结论只作链路验收；真实业务需更多坏样本或重采样 |
| 2 | **宽表必然过拟合** | 691 个可分析特征 + 35 坏样本：lgb 典型 train AUC≈0.997、val AUC≈0.63（实测）；示例数据上 val KS≈0.402 | 上线前 `feature_refine`、降 `num_leaves`/`max_depth`、补坏样本；**不要**把 train 指标当模型能力 |
| 3 | **test 子集可能只剩一类** | 划分比例小 / 坏样本少时，某子集只有好或只有坏 ⇒ 指标 `status="skipped"` + `reason`，不编 0 冒充满分 | 看 `metrics.json` 的 `status`/`reason`；需要 test 指标就增大 test 比例或补样本 |
| 4 | **LIFT 可能等于 0** | 尾部 10% 一个坏样本都没抓到 ⇒ `LIFT=0` 是**真实值**，不是 bug | 看 `lift_seg_size` / `is_reliable`；坏率极低时 LIFT 不宜作主结论 |
| 5 | **PSI 可能不可用** | 无时间列 / 只有 1 个月 / 基期覆盖全部月份 ⇒ `psi.enabled=false` + `reason`，**不伪造数值** | 看 `reason`；此时 `model_confirm` 只校验 KS，并在 warnings 明示「不代表跨期稳定」 |
| 6 | **默认 PSI 基期是单月** | 多个月合并池需显式 `config.psi_base_months`；指定的基期月不存在 ⇒ `config_invalid`（不静默回落） | 跨年/跨口径月份合并需业务确认，工具不替用户判断 |
| 7 | **LR 在宽表上可能不收敛** | 未缩放/未筛选时 sklearn `ConvergenceWarning` → warnings「训练未收敛，系数不可信」；不自动缩放（会改变系数口径） | 先筛选/缩放；或换树模型 |
| 8 | **gbdt（sklearn）明显慢** | 单线程逐树串行，691 列上约 9 s/100 棵 | 宽表优先 `xgb` / `lgb` |
| 9 | **不做 OOT / 外部验证** | `tune_on` 结构性只允许 `val`；`model_evaluate` 只算 train/val/test | 外部验证在本项目范围外 |
| 10 | **不做回归 / 深度学习 / 服务化** | 契约冻结 20 工具，只做二分类/多分类表格建模 | 超出范围的需求另立项目 |
| 11 | **`final/model.pkl` 是 run 模型副本** | 确认不重新训练、不改标尺 | 需要新模型就重新 `model_train` 再确认 |

## 2. 运行环境与依赖边界

| # | 边界 | 事实 / 影响 | 处置 |
|---|---|---|---|
| 12 | **`pyarrow` 未安装** | 预处理产物落 `processed.csv`（降级），`warnings` 明示；模型层会读取 CSV，读数一致 | 可选 `python -m pip install pyarrow` 换成 `processed.parquet` |
| 13 | **中文字体缺失** | 图表中文可能显示为方块；`doctor` 的 `chinese_font` 只 WARN，不阻断 | Windows 启用微软雅黑；Linux 装 `fonts-noto-cjk`；不影响数值 |
| 14 | **macOS / Linux 未实测** | 代码无 POSIX-only 依赖（`tests/test_platform.py` 静态守护），但只在 Windows 上真跑过 | 上其他平台前先跑 `doctor` + 全量测试 |
| 15 | **MCP SSE / streamable-http 未实测** | 只实测 stdio；三客户端接入均为 stdio | 需要 HTTP 传输时自行验证 |
| 16 | **示例数据不随仓库分发** | 基准宽表（2000 行 × 696 列）不在仓库内；测试在样例缺失时自动 skip | 用自己的 CSV 跑；宽表分析耗时以实际数据为准 |
